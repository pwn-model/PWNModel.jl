# PWN model experiments

This site shows small experiments with the pine wilt nematode (PWN) model.
Each experiment looks at a single part of the model under simple, controlled conditions,
for example how beetles move through a forest, or how strongly trees attract them.
The aim is to make the model's behaviour visible and open for discussion.

The experiments are listed in the navigation menu.

For the full model description, see the [model specification](https://github.com/pwn-model/model-spec).

## Reading the experiment pages

Each experiment page has the same structure:

- **Question**: what the experiment is about.
- **Setup**: the landscape and the model settings used.
  Names in `code font` are model parameters, as named in the model specification.
- **Figures**: the results.
- **Observations**: what we see in the figures.

The pages also contain short technical notes on how to run the experiments. These can be skipped.

All results are recalculated automatically with the latest version of the model whenever it changes.
